# Clocky v0.3.1 — TUI action labels without icons

Patch release cleaning decorative symbols from the Terminal UI action buttons.

## Fix

- Remove play/stop and related geometric icons from hub actions (`Start Stopwatch`, `Stop Stopwatch`, `New Pomodoro`, `New Timer`, `Stop Timer`)
- Labels are plain text only (no emoji / icon glyphs)

## Install / update

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.ps1 | iex
```

Or, if Clocky is already installed:

```powershell
clocky update --yes
```

**macOS / Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.sh | bash
# or
clocky update --yes
```

Pin this release with `CLOCKY_VERSION=v0.3.1`.
