# Clocky v0.1.0

First public release of **Clocky** — a cross-platform terminal time manager for Windows, macOS, and Linux.

## Highlights

- **Pomodoro** with a live ASCII analog clock (minute + second hands, 12/3/6/9 marks)
- **Background timer** with beep, ASCII banner, and native OS notifications
- **Stopwatch** toggle (start / stop → elapsed `HH:MM:SS`)
- **Named presets** for pomodoros and timers (`clocky add` / `list` / `remove`)
- **Flexible durations** (`:25:`, `::50`, `24::`, overflow like `:1440:`)
- **Install & self-update** from GitHub Releases (`clocky update`)

## Install

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.ps1 | iex
```

**macOS / Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.sh | bash
```

Pin this release:

```bash
# Unix
CLOCKY_VERSION=v0.1.0 curl -fsSL https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.sh | bash

# Windows PowerShell
$env:CLOCKY_VERSION = 'v0.1.0'
irm https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.ps1 | iex
```

Defaults: `%LOCALAPPDATA%\Clocky` (Windows), `~/.local/bin` (Unix). Override with `CLOCKY_INSTALL_DIR`.

## Quick start

```bash
clocky pomodoro
clocky pomodoro --focus 40 --break 10 --long 15 --cycles 4 --auto

clocky timer :25:
clocky timer --stop
clocky status

clocky stopwatch   # start
clocky stopwatch   # stop

clocky add pomodoro --name Focus --focus 40 --break 10 --long 15 --cycles 4
clocky add timer --name Break ::300
clocky list
clocky pomodoro Focus
```

## What's included

### Pomodoro

- Focus / short break / long break cycles
- Larger ASCII face (~31×16) with remaining-time **minute** (`#`) and **second** (`*`) hands
- Cardinal marks at 12 / 3 / 6 / 9
- Flags: `--focus`, `--break`, `--long`, `--cycles`, `--auto`
- Phase-end notifications (beep + banner + native)

### Timer

- Detached background countdown (no always-on daemon)
- State under `~/.clocky/`
- `clocky timer --stop` and `clocky status`
- Completion: beep, banner, native notification

### Stopwatch

- First call starts; second call stops and prints elapsed time

### Presets & duration

- Save and reuse named pomodoro/timer presets
- `H:M:S` parser with empty fields and overflow into larger units

### Distribution

- GitHub Releases via GoReleaser (Windows / macOS / Linux, amd64 + arm64)
- SHA256 checksum verification on install and update
- `clocky version` / `clocky update` / `clocky update --check` / `clocky update --yes`
- Safe binary replace on Windows (`.new` / `.old`)

## Platform support

## Notes

- CLI and messages are in **English**
- Requires a terminal that supports basic ANSI clear/home for the live pomodoro face
- Native notifications depend on the OS notification stack (may be silent if disabled by the user)
