# Clocky v0.3.2 — Pomodoro tick fixes and background session controls

Patch release fixing pomodoro timing bugs in the Terminal UI and rounding out background-session handling.

## Fixes

- Pomodoro no longer counts at double speed after minimizing (Esc) or reopening it from the hub — the app now owns a single perpetual tick loop instead of scheduling one per page transition
- Pomodoro launched from the New Pomodoro form now counts down inside the session view (the tick loop no longer dies on form/picker/confirm pages)
- Phase-end alarm no longer stacks multiple audio loops

## Improvements

- Minimize (Esc/b), Open and Stop a running pomodoro from the hub without destroying the session
- Waiting pomodoro (non-auto) advances with Enter directly from the hub
- Phase-end notice on the hub with desktop notification; Esc dismisses the alarm
- Hub Active panel stays in sync with the running pomodoro after every tick

## Install / update

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.ps1 | iex
```

Or, if Clocky is already installed:

```powershell
clocky update --yes
```

**macOS / Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.sh | bash
# or
clocky update --yes
```

Pin this release with `CLOCKY_VERSION=v0.3.2`.
