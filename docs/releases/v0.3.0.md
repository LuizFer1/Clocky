# Clocky v0.3.0 — TUI hub polish and timer alarm

Improves the Terminal UI experience: fullscreen layout, clearer actions, and an in-hub timer alarm.

## Highlights

- **Fullscreen centered hub** with a block-letter **CLOCKY** banner
- **Action buttons:** New Pomodoro, New Timer, Start/Stop Stopwatch (one toggle), Stop Timer (when running)
- **Launch forms** with full parameters (optional save as preset)
- **Preset navigation:** `↑↓` for presets, `←→` for actions, `Enter` to start
- **Timer finished notice** in the hub + **MessageBeep alarm** every 1.25s until `Esc`
- **Windows toast** no longer flashes a PowerShell window

## Install / update

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.ps1 | iex
```

Or, if Clocky is already installed:

```powershell
clocky update --yes
```

**macOS / Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.sh | bash
# or
clocky update --yes
```

Pin this release with `CLOCKY_VERSION=v0.3.0`.

## Try it

```text
clocky
```

Start a short timer from **New Timer**, leave the hub open, hear/see the alarm, press **Esc** to stop.
