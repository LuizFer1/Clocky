# Clocky v0.1.1

Patch release fixing the live pomodoro display on **Windows PowerShell**.

## Fix

- Enable Windows **virtual terminal** processing for the console
- Clear the screen via ANSI when VT is available, or the native console API as fallback
- Stops printing raw escape codes like `←[H←[2J` and scrolling a new clock every second

## Install / update

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.ps1 | iex
```

Or, if Clocky is already installed:

```powershell
clocky update --yes
```

**macOS / Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.sh | bash
# or
clocky update --yes
```

## Verify

```powershell
clocky version
clocky pomodoro --focus 1 --break 1 --long 1 --cycles 1 --auto
```

The clock should redraw in place each second (no `←[H←[2J` text, no scrolling stack of faces).
