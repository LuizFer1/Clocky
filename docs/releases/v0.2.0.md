# Clocky v0.2.0 — Simple TUI hub and visual

Feature release adding an interactive Terminal UI for managing pomodoros, timers, stopwatch, and presets — with a richer on-screen layout while keeping the CLI for scripts.

## Highlights

- **`clocky` opens the TUI** in an interactive terminal (help when non-TTY)
- **Hub** with live Active panel (timer remaining, stopwatch elapsed) and Presets list
- **Preset CRUD** in the TUI (create, edit, delete, start)
- **Pomodoro session** view: ASCII analog clock, block progress bar, **pause/resume**, skip, return to hub
- Timer and stopwatch **keep running after quitting** the TUI (same `~/.clocky/` state as the CLI)
- Visual style: panels, colors, box-drawing and block characters — **no emoji**
- Existing CLI commands unchanged (`pomodoro`, `timer`, `stopwatch`, `add`, `list`, …)

## Install / update

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.ps1 | iex
```

Or, if Clocky is already installed:

```powershell
clocky update --yes
```

**macOS / Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/LuizFer1/Clocky/main/scripts/install.sh | bash
# or
clocky update --yes
```

Pin this release with `CLOCKY_VERSION=v0.2.0`.

## Try the TUI

```text
clocky
```

Keys (hub): `↑↓` select · `Enter` start · `n` new · `e` edit · `d` delete · `s` stop timer · `t` stopwatch · `p` pomodoro · `q` quit
